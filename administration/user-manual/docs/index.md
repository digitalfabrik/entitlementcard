# Benutzerhandbuch

Dieses Handbuch beschreibt die wichtigsten Abläufe der Verwaltung der Digitalen Berechtigungskarte.
Die Kapitel sind nach Projekten gegliedert:

- **Bayern** – Ehrenamtskarte
- **Nürnberg** – Nürnberg-Pass
- **Koblenz** – KoblenzPass

Jedes Kapitel nennt die Rollen, für die ein Ablauf verfügbar ist, die einzelnen Schritte und das Ergebnis.

Die Anleitungen werden automatisch aus den Tests der Verwaltung erzeugt. Jeder beschriebene Ablauf wird
vor jeder Veröffentlichung automatisch geprüft, das Handbuch ist daher immer auf dem aktuellen Stand.
